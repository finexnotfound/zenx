📲 How to Install ZEN X on Android

  1. Click the big green "Download ZEN-X.apk" button above.
  2. Once downloaded, open the ZEN-X.apk file from your browser downloads or file manager.
  3. If prompted, enable "Allow installation from this source" in your Android settings.
  4. Tap Install and open ZEN X to start your terminal session!
